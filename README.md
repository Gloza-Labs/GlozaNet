# GlozaNet
GlozaNet is a modern, lightweight web browser focused on speed, simplicity, and a clean, customizable UI. Featuring sleek Gloza-inspired design, smooth tab management, intuitive menus, and a modern browsing experience, it brings a fresh look to everyday web browsing.

# WARNING
GlozaNet is in public beta - attempt at your own risk.

## ✨ Features

- 🎨 **Modern UI** — Clean design with Gloza's signature look.
- 🗂️ **Tab Management** — Open, switch between, and rearrange tabs.
- 🔖 **Bookmarks** — Save your favorite websites and access them easily.
- ⬇️ **Downloads** — Manage your downloads directly from the browser.
- 🔍 **Smart Address Bar** — Enter URLs and navigate the web easily.
- 🖱️ **Context Menus** — Quickly access useful actions with a right-click.
- 🔎 **Zoom Controls** — Adjust the zoom level of web pages.
- 💚 **Gloza Style** — A modern browsing experience designed to fit the Gloza ecosystem.

## 🖥️ Supported systems

- Windows 10/11
- MacOS 12 (Monterey) or higher

## 📥 How to Download

1. Go to the [Releases](https://github.com/Gloza-Labs/GlozaNet/releases/tag/GlozaNet) page.
2. Download the latest GlozaNet release from **Assets**.
3. Open the downloaded file and install or run GlozaNet.

### 🛡️ Windows SmartScreen

Windows might show a **“Windows protected your PC”** message when you first open GlozaNet setup.

To continue, click **More info**, then click **Run anyway**.

## 💚 Enjoy browsing!

GlozaNet is in progress, and more improvements and features are coming as development continues.
