Website Appearance

Control how websites themselves are displayed — independent of Gloza's own theme.

Force dark mode on websites Darkens pages that don't offer their own dark theme. Sites that already support dark mode are left alone. This can't work perfectly on every page — some may look odd; use a site exception below if one does.
Site exceptions Websites where forced dark mode is turned off, even while the setting above is on.

Ad Blocker

Gloza's built-in ad and tracker blocker — no extension required.

Block ads and trackers Blocks matching requests browser-wide, using Gloza's own filtering engine.
YouTube ad blocking Two independent methods. You can run either alone or both together — turning one off never turns off the other.
Method 1 — Network filter blocking Blocks YouTube's ad/tracking requests (and third-party ad networks) at the network level, via the filter lists below.
Method 2 — YouTube-specific blocking A YouTube-specific layer: strips ad data from the player response before it loads (so most ads never get scheduled at all), and auto-clicks the native Skip button / hides ad overlays as a fallback, in the main player and embedded players.
